# Corali AC Probe v2 — διάγνωση κλιματιστικών (μόνο ανάγνωση, χωρίς πρόσθετο hardware)

Για το Hotel Corali ισχύει: **κανένα πρόσθετο hardware**. Το εργαλείο χρησιμοποιεί μόνο τα **εργοστασιακά Wi-Fi modules**
των κλιματιστικών και έναν υπολογιστή / Raspberry Pi που **ήδη υπάρχει** στο ίδιο δίκτυο (π.χ. η γέφυρα Omada).

Το εργαλείο **δεν στέλνει καμία εντολή λειτουργίας** (ON/OFF, θερμοκρασία, λειτουργία). Δεν περιλαμβάνεται στο πακέτο
εγκατάστασης του PMS — διανέμεται χωριστά (`corali-diagnostics-v201.tar.gz`).

## Τι ελέγχει

| Έλεγχος | Πώς | Στέλνει κάτι στο κλιματιστικό; |
|---|---|---|
| IP / MAC / κατασκευαστής module | πίνακας γειτόνων του υπολογιστή (ARP) + πρόθεμα MAC | όχι |
| Tuya (Inventor Control, Smart Life) | ακρόαση εκπομπών UDP 6666/6667/7000 | όχι |
| BroadLink (AUX, AC Freedom) | τυπικό μήνυμα ανακάλυψης | μόνο ερώτηση «ποιος είσαι» |
| Θύρες 6668 / 80 | σύνδεση TCP και αμέσως κλείσιμο | όχι δεδομένα |
| Τοπική σύνδεση BroadLink (`--broadlink-auth`) | auth — χωρίς ανάγνωση/εντολή | μόνο σύνδεση |
| Θερμοκρασία χώρου / setpoint | **μόνο** Tuya με local key (`--tuya-…`) — `status()` | μόνο ανάγνωση |

Κατάταξη ανά συσκευή — τι έχει **αποδειχθεί** για την τοπική (LAN) πρόσβαση. Η ανακάλυψη μόνη της δεν αποδεικνύει
ότι το κλιματιστικό ελέγχεται μέσω LAN:

- `AUTHENTICATED` — πέτυχε τοπική σύνδεση (BroadLink auth, ή ανάγνωση κατάστασης Tuya με το local key).
- `DISCOVERED_UNVERIFIED` — το module απάντησε στην ανακάλυψη, αλλά δεν δοκιμάστηκε (ή δεν υπάρχει κλειδί) τοπική σύνδεση.
- `AUTH_FAILED` — το module απάντησε και απέρριψε την τοπική σύνδεση (κλειδί / κλείδωμα / πρωτόκολλο).
- `NETWORK_ERROR` — δεν απάντησε στη σύνδεση (timeout, μη προσβάσιμο): **ακαθόριστο**, ξανατρέξτε — δεν σημαίνει κλείδωμα.
- `LOCAL_LOCKED` — το BroadLink module δηλώνει ότι είναι κλειδωμένο → μόνο μέσω cloud (AC Freedom).
- `CLOUD_ONLY_OR_UNKNOWN` — δεν απαντά σε γνωστό τοπικό πρωτόκολλο.

Όταν δίνεται `--tuya-ip`, η συγκεκριμένη μονάδα ελέγχεται **πάντα**, ακόμη κι αν δεν εμφανίστηκε στη σάρωση (π.χ. όταν
το access point απομονώνει τους πελάτες ή η μονάδα είναι σε άλλο VLAN). Χρειάζονται μαζί `--tuya-id`, `--tuya-ip` και το
local key.

Για AUX: η ανάγνωση θερμοκρασίας/setpoint μέσω BroadLink απαιτεί το ειδικό πρωτόκολλο AUX· θα προστεθεί **μόνο** αφού η
αναφορά δείξει ότι το module δέχεται τοπική σύνδεση (`AUTHENTICATED`).

## Εγκατάσταση (μία φορά)

```bash
sudo apt-get install -y python3-venv
python3 -m venv ~/ac-probe && ~/ac-probe/bin/pip install tinytuya broadlink
```

## Εκτέλεση

Τα κλιματιστικά ρευματοδοτημένα και συνδεδεμένα στο Wi-Fi (από τις εφαρμογές τους), στο ίδιο δίκτυο με τον υπολογιστή.

```bash
~/ac-probe/bin/python ac_probe.py --broadlink-auth
```

Ανάγνωση μίας μονάδας Tuya όταν υπάρχει local key (το κλειδί μπορεί να δοθεί και ως μεταβλητή `CORALI_TUYA_KEY`):

```bash
CORALI_TUYA_KEY='…' ~/ac-probe/bin/python ac_probe.py --tuya-id DEVICE_ID --tuya-ip 192.168.x.y --tuya-version 3.3
```

## Επίπεδα συμβατότητας και τα δύο αρχεία

Κάθε συσκευή παίρνει επίπεδο: `DISCOVERED` → `AUTHENTICATED` → `STATUS_READ` (το εργαλείο φτάνει το πολύ εδώ — δεν
στέλνει εντολές). Το `COMMAND_CONFIRMED` καταγράφεται μόνο στο PMS (Δωμάτια → Συμβατότητα κλιματιστικών), μετά από
δοκιμή εντολής με ανάγνωση πριν και μετά.

- `ac-probe-report.json` — **προστατευμένα διαγνωστικά**: περιέχει IP, MAC και τεχνικά αναγνωριστικά (όχι κλειδιά).
  Δικαιώματα αρχείου 600. Εισάγεται στο PMS (Συμβατότητα κλιματιστικών → «Εισαγωγή αναφοράς»), όπου τα αναγνωριστικά
  τα βλέπουν μόνο όσοι διαχειρίζονται τα δωμάτια. Μην το στέλνετε σε τρίτους.
- `ac-probe-report-share.json` — **για κοινή χρήση**: χωρίς IP, MAC, device id και product key (κάθε συσκευή ως
  `dev-1`, `dev-2`…), με επίπεδα, πρωτόκολλα και ευρήματα. Ελέγχεται πριν γραφτεί ότι δεν περιέχει κανένα από αυτά.

## Ιδιωτικότητα

Το `ac-probe-report.json` **δεν περιέχει** κωδικούς, local keys, όνομα δικτύου (SSID), όνομα υπολογιστή ή συσκευές
πελατών: καταγράφονται μόνο modules γνωστών κατασκευαστών IoT ή όσα απάντησαν σε ανακάλυψη· οι υπόλοιπες συσκευές
μετριούνται μόνο. Πριν γραφτεί το αρχείο, ελέγχεται ότι το local key δεν εμφανίζεται πουθενά σε αυτό.
