# Κέντρο ασφαλείας και κλείδωμα πίσω από το Cloudflare (v180)

PMS → **Ρυθμίσεις → Κέντρο ασφαλείας** (`/pms/security`).

## Τι δείχνει
- **Κλείδωμα πίσω από το Cloudflare**: αν το PMS δέχεται μόνο αιτήματα που περνούν από το Cloudflare.
- **2FA**: ποιοι χρήστες με δικαιώματα διαχείρισης (owner / admin / manager) δεν έχουν κωδικό δύο βημάτων.
- **Αποτυχημένες συνδέσεις** στο PMS (24 ώρες).
- **Ύποπτα αιτήματα** των τελευταίων 7 ημερών: λάθος κλειδί API, λάθος κλειδί γέφυρας Wi-Fi, άγνωστη τηλεόραση,
  webhooks με λάθος υπογραφή, αιτήματα που κόπηκαν από το όριο προσπαθειών, αιτήματα που παρέκαμψαν το Cloudflare.

Κάθε ώρα (στο :07) γίνεται αυτόματος έλεγχος. Κάθε νέο πρόβλημα έρχεται **μία φορά** ως ειδοποίηση στο καμπανάκι.

## Κλείδωμα πίσω από το Cloudflare (μία φορά)
Η διεύθυνση του server είναι δημόσια (μέσω της εγγραφής `mx` του email), οπότε κάποιος μπορεί να τον χτυπήσει απευθείας
και να παρακάμψει το Cloudflare. Με το κλείδωμα, το Cloudflare βάζει ένα μυστικό κλειδί σε κάθε αίτημα και το PMS
απορρίπτει όσα δεν το έχουν.

1. PMS → Κέντρο ασφαλείας → **Δημιουργία κλειδιού**. Αντιγράψτε το κλειδί (`ce_…`), γιατί εμφανίζεται μόνο μία φορά.
2. Cloudflare → **hotelcorali.gr → Rules → Overview → Create rule → Request Header Transform Rule**:
   - Rule name: `Corali origin key`
   - **All incoming requests**
   - Then: **Set static** · Header name: `x-corali-edge` · Value: το κλειδί
   - **Deploy**
3. Σε 1 λεπτό η κατάσταση στο PMS γράφει **«Το Cloudflare στέλνει το κλειδί ✓»**.
4. Πατήστε **Ενεργοποίηση κλειδώματος**.

**Δεν κλειδώνεστε ποτέ έξω.** Αν ο κανόνας του Cloudflare σβηστεί ή αλλάξει, μετά από 30 λεπτά χωρίς κλειδί το PMS
ανοίγει μόνο του και έρχεται ειδοποίηση. Ο έλεγχος υγείας (`/api/health`) δεν κλειδώνεται ποτέ.

## Η διεύθυνση του επισκέπτη
Από τη v180 το PMS εμπιστεύεται μόνο τη διεύθυνση που γράφει το Cloudflare (`CF-Connecting-IP`). Πριν, η πρώτη τιμή του
`X-Forwarded-For` μπορούσε να είναι ψεύτικη, και κάποιος μπορούσε έτσι να παρακάμψει το όριο προσπαθειών ανά διεύθυνση
(π.χ. στη σύνδεση «Η κράτησή μου»).

## Ρυθμίσεις που έγιναν στο Cloudflare / cPanel (20/11/2026)
- SSL/TLS **Full (strict)**, **Always Use HTTPS**, Minimum TLS **1.2**.
- Managed ruleset ενεργό, **Bot Fight Mode κλειστό**: στο δωρεάν πακέτο δεν δέχεται εξαιρέσεις και θα έκοβε τις
  τηλεοράσεις, τη γέφυρα και τα webhooks.
- **Cloudflare Access** (Zero Trust Free) στο `cpanel.hotelcorali.gr` (και `whm.`): είσοδος με κωδικό στο email.
- cPanel **ModSecurity On** για `hotelcorali.gr`, `pms.`, `booking.`.
- Δίκτυο ξενοδοχείου: VLAN 30 «IOT» με κρυφό Wi-Fi `CRL-SYS` για τηλεοράσεις / πρίζες / αισθητήρες. Κανόνες ACL
  IOT ↔ Default. Το `CORALI_ROOMS` είναι Guest Network.
