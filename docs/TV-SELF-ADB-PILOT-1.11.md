# Corali TV 1.11 — πιλοτικός έλεγχος «ADB μέσα στην TV» (HORIZON 112)

Σκοπός: να δούμε αν η εφαρμογή Corali TV μπορεί να συνδεθεί στο ADB της **ίδιας** τηλεόρασης, ώστε στο μέλλον ο καθαρισμός στο check-out να γίνεται χωρίς υπολογιστή-gateway. **Μόνο ανάγνωση**: εκτελείται μόνο `pm list packages -3`. Τίποτα δεν σβήνεται ή αλλάζει.

## Τι περιέχει
- `SelfAdbProbe.java`: δική μας υλοποίηση του πρωτοκόλλου ADB (χωρίς βιβλιοθήκη AdbLib). Σταθερός προορισμός `127.0.0.1:5555`, σταθερή εντολή, κλειδί RSA μόνο στον ιδιωτικό χώρο της εφαρμογής.
- Κουμπί «Έλεγχος τοπικού ADB (μόνο ανάγνωση)» στην οθόνη ρυθμίσεων (Πίσω 3″). Αποτελέσματα: `PASS`, `PORT_CLOSED`, `AUTH_REJECTED`, `TIMEOUT`, `TLS_REQUIRED`, `COMMAND_FAILED`, `PROTOCOL_ERROR`, και αν χρειάστηκε νέα έγκριση στην TV.
- Ίδια υπογραφή, ίδιο πακέτο `gr.hotelcorali.tv`: εγκαθίσταται πάνω από την 1.10 χωρίς απώλεια ρυθμίσεων. Τίποτα άλλο δεν άλλαξε (καλωσόρισμα, ήχος, σύνδεση PMS).
- Το APK **δεν** δημοσιεύεται στο `/tvapp`: μπαίνει μόνο στην TV 112.

## Εγκατάσταση (από τον υπολογιστή με ADB)
```
cd %USERPROFILE%\Desktop\platform-tools
adb connect 192.168.10.120:5555
adb install -r %USERPROFILE%\Downloads\corali-tv-1.11-pilot.apk
```
`-r` = αναβάθμιση, κρατά τα δεδομένα. Αναμένεται `Success`.

## Δοκιμή
1. Η TV δείχνει κανονικά το καλωσόρισμα του 112. Έλεγχος: ήχος, Google, σύνδεση PMS.
2. Κρατήστε **Πίσω 3″** → ρυθμίσεις → κάτω η έκδοση `v1.11` → «Έλεγχος τοπικού ADB».
3. Στην TV εμφανίζεται «Να επιτρέπεται ο εντοπισμός σφαλμάτων;» → τσεκάρετε «Να επιτρέπεται πάντα» → OK. Αναμένεται `✓ PASS` + λίστα εφαρμογών.
4. Πατήστε ξανά: `✓ PASS` + «Χωρίς νέα έγκριση».
5. **Βγάλτε την TV από την πρίζα 60″.** Ανάψτε τη, περιμένετε 2′, **χωρίς** υπολογιστή / `adb connect`.
6. Πίσω 3″ → «Έλεγχος τοπικού ADB». Αποτέλεσμα:
   - `✓ PASS` + «Χωρίς νέα έγκριση» → **επιτυχία**: προχωράμε σε καθαρισμό μέσα από την TV.
   - `PORT_CLOSED` → η TV κλείνει το ADB μετά από διακοπή ρεύματος → η λύση δεν είναι αξιόπιστη (μένει gateway).
   - `PASS` αλλά «Χρειάστηκε έγκριση» → η TV ξεχνά την έγκριση → όχι αξιόπιστη.
7. Φωτογραφία της οθόνης σε κάθε βήμα.

## Επαναφορά
`adb install -r -d corali-tv.apk` (1.10 από `/tvapp`), ή απλώς αφήστε την 1.11: το κουμπί δεν κάνει τίποτα αν δεν πατηθεί.

## Ασφάλεια
Το ADB στη θύρα 5555 είναι ήδη ανοιχτό στην TV από τη ρύθμιση με τον υπολογιστή. Στην παραγωγή οι TV πρέπει να είναι σε δίκτυο χωριστό από το Wi-Fi επισκεπτών. Μην ενεργοποιείτε ποτέ port forwarding της 5555 στον router.

## Δοκιμές που έγιναν (χωρίς TV)
JVM απέναντι σε προσομοίωση ADB που επαληθεύει πραγματικά την υπογραφή RSA και τη μορφή κλειδιού (`android-tv/test`): πρώτη σύνδεση με έγκριση → PASS · δεύτερη → PASS χωρίς έγκριση · απόρριψη → AUTH_REJECTED · χωρίς απάντηση → TIMEOUT · μη εγκεκριμένο εγκαίρως → TIMEOUT · κλειστή θύρα → PORT_CLOSED · άκυρες γραμμές φιλτράρονται · η μόνη εντολή που στάλθηκε: `shell:pm list packages -3`. Build/υπογραφή APK OK (versionCode 12).
