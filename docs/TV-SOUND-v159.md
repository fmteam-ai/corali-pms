# Corali TV — Ήχος & Hotel Mode (PMS v159, εφαρμογή 1.9)

Τηλεόραση δοκιμής: HORIZON 43HQ8590U/D, Android 14 (Google TV), δωμάτιο 112. Βασίζεται στον μηχανισμό εντολών με
επιβεβαίωση της v158 (`tv_screen_commands`). Δεν προστέθηκε δεύτερος μηχανισμός επικοινωνίας.

## 1. Κατάσταση ανά δυνατότητα

| Δυνατότητα | Υλοποιήθηκε | Δοκιμάστηκε (ανάπτυξη) | Δοκιμή στη HORIZON | Σημείωση |
|---|---|---|---|---|
| Ένταση: ορισμός %, +, − | ✓ | ✓ ροή εντολής / επιβεβαίωσης | **εκκρεμεί** | `AudioManager.STREAM_MUSIC`· η τιμή διαβάζεται μετά την αλλαγή |
| Σίγαση / ήχος | ✓ | ✓ | **εκκρεμεί** | `ADJUST_MUTE / ADJUST_UNMUTE` |
| Ανάγνωση τρέχουσας έντασης | ✓ | ✓ | **εκκρεμεί** | σε κάθε έλεγχο (~20″) |
| Ένταση στο άναμμα (policy) | ✓ | ✓ αποστολή πολιτικής | **εκκρεμεί** | στο `SCREEN_ON` της TV και στην εκκίνηση της εφαρμογής |
| Μέγιστη ένταση (policy) | ✓ **λογισμικό** | ✓ όριο σε εντολές | **εκκρεμεί** | best effort: το τηλεχειριστήριο μπορεί να την ξεπεράσει για λίγα δευτερόλεπτα, και η εφαρμογή την επαναφέρει (παρακολούθηση αλλαγών + κάθε 20″). **Δεν είναι εργοστασιακό κλείδωμα.** |
| Μαζικές ενέργειες (επιλεγμένα / όλα) | ✓ | ✓ αποτέλεσμα ανά δωμάτιο | **εκκρεμεί** | κάθε δωμάτιο: σε αναμονή / εκτελέστηκε / απέτυχε / χρειάζεται 1.9 |
| Εργοστασιακό `hotel_max_volume` | — | — | — | **Δεν υποστηρίζεται:** καμία εξουσιοδοτημένη πρόσβαση. Η τιμή **διαβάζεται μόνο**, αν η TV το επιτρέπει. |
| Εργοστασιακό `hotel_power_volume` | — | — | — | Όπως παραπάνω |
| Κλείδωμα μενού (`hotel_menu_key_lock`) | — | — | — | **Δεν υποστηρίζεται.** Δεν είναι γνωστό τι κλειδώνει και δεν υπάρχει τεκμηριωμένο API. Φαίνεται στο PMS ως «Δεν υποστηρίζεται». |
| Κλείδωμα πηγής (HDMI) | — | — | — | **Δεν υποστηρίζεται** (καμία εξουσιοδοτημένη πρόσβαση) |
| Πλήρες κλείδωμα Android Settings | — | — | — | Θα απαιτούσε Android Enterprise **Device Owner** (επαναφορά εργοστασιακών ρυθμίσεων + ADB). Να αξιολογηθεί χωριστά. |
| Αφύπνιση δικτύου | — | — | — | Όπως στη v158: δεν υπάρχει λειτουργικός μηχανισμός (TV-POWER-v158.md) |

Τι **δεν** χρησιμοποιείται: Binder transaction IDs, factory broadcasts, εγγραφή σε ρυθμίσεις του κατασκευαστή, root,
αλλαγές SELinux, αντικατάσταση system APK, πρόσβαση στα `com.realtek.power.*`.

## 2. Ανίχνευση δυνατοτήτων (μόνο ανάγνωση)

Κάθε 10′ η εφαρμογή στέλνει `caps` και το PMS κρατά μόνο γνωστά κλειδιά:

| Κλειδί | Πώς ανιχνεύεται |
|---|---|
| `volume`, `mute`, `fixedVolume` | `AudioManager.isVolumeFixed()` (π.χ. ήχος από HDMI ARC σε soundbar → η εφαρμογή δεν αλλάζει την ένταση και κάθε εντολή αποτυγχάνει με `FIXED_VOLUME`) |
| `factoryApp` | αν υπάρχει το πακέτο `com.expressluck.tvfactory` |
| `factoryHotelMode`, `factoryMaxVolume`, `factoryPowerVolume`, `factoryMenuLock` | `Settings.Global/System/Secure.getString("hotel_…")`: «read: τιμή» ή «not readable». **Ποτέ εγγραφή.** |

Το αποτέλεσμα φαίνεται στη στήλη «Δυνατότητες» για κάθε δωμάτιο. Η αναφορά συμβατότητας της HORIZON συμπληρώνεται από αυτή τη στήλη μετά την εγκατάσταση της 1.9 στο 112.

## 3. Εντολές και επιβεβαίωση

Νέες εντολές στο `tv_screen_commands`: `SET_VOLUME` (με `value` και το όριο `cap` της πολιτικής), `VOLUME_UP`, `VOLUME_DOWN`, `MUTE`, `UNMUTE`.

Η εφαρμογή αναφέρει την ένταση και τη σίγαση **όπως τις διαβάζει μετά την αλλαγή**. Το PMS κρίνει:

- `SET_VOLUME`: **EXECUTED** αν η τιμή απέχει έως 7 μονάδες από τον στόχο (με το όριο). Τα 7 μονάδες καλύπτουν τα βήματα έντασης του Android.
- `MUTE` / `UNMUTE`: με βάση την ένδειξη σίγασης.
- `+` / `−`: όταν διαβάστηκε νέα τιμή.
- Σταθερή ένταση → **FAILED** (`FIXED_VOLUME`).

Οι εντολές ήχου δουλεύουν σε κάθε δωμάτιο με εφαρμογή 1.9, ανεξάρτητα από τη μέθοδο ρεύματος. Οι εντολές οθόνης δουλεύουν μόνο με «Εφαρμογή Corali TV». Ισχύουν όπως στη v158 η μία μόνο παράδοση, η λήξη (5′), το UNVERIFIED (2′) και η ακύρωση από νεότερη εντολή.

## 4. Βάση δεδομένων (schema v159)

- `tv_sound_policies (owner_id, room_id)` → `default_volume`, `max_volume` (0–100, με έλεγχο ότι η προεπιλογή ≤ μέγιστο), `enforce_max`, `updated_by`, `updated_at`. Αυτή είναι η *επιθυμητή* κατάσταση.
- `tv_screens.volume_percent / volume_muted / volume_fixed / caps_json / policy_clamped_at` είναι η *αναφερόμενη* κατάσταση, χωριστά από την επιθυμητή.
- `tv_screen_commands.value / cap / result_volume / result_muted`.
- Χωρίς δεύτερο αναγνωριστικό δωματίου: `room_id` όπως στα `tv_screens` / `rooms`.

## 5. API

| Endpoint | Δικαίωμα | Τι κάνει |
|---|---|---|
| `GET /api/pms/tv/sound` | reservations.read | κατάσταση, πολιτικές, τελευταίες εντολές |
| `POST /api/pms/tv/sound {action:"command", roomIds, command, value}` | **reservations.write** (ρεσεψιόν) | εντολή σε ένα ή πολλά δωμάτια· αποτέλεσμα ανά δωμάτιο |
| `POST /api/pms/tv/sound {action:"policy", roomIds, policy}` | **integrations.write** (διαχειριστής) | πολιτική ήχου για ένα ή πολλά δωμάτια |
| `GET /api/public/tv/<token>/urgent?…&vol&mute&fixed&clamped&caps` | token δωματίου | αναφορά τηλεόρασης· επιστρέφει εντολή + πολιτική |
| `POST /api/public/tv/<token>/command` | token δωματίου | αποτέλεσμα εντολής με ένταση / σίγαση |

Όλα τα `POST` του PMS: έλεγχος origin και καταγραφή στο ιστορικό ενεργειών (`tv_sound`). Η καμαριέρα και οι επισκέπτες δεν έχουν πρόσβαση.

## 6. PMS

PMS → Corali TV → **«Ήχος & Hotel Mode»**. Για κάθε δωμάτιο:
- τηλεόραση (online / offline / οθόνη), ένταση και σίγαση όπως τις αναφέρει η TV,
- slider, Ορισμός, −, +, Σίγαση / Ήχος,
- πολιτική (ένταση στο άναμμα, μέγιστη, επιβολή μεγίστου),
- δυνατότητες, τελευταία εντολή με κατάσταση και τιμή που διαβάστηκε.

Μαζικά: επιλογή δωματίων / όλων → ένταση, σίγαση, ήχος, εφαρμογή πολιτικής. Το κλείδωμα μενού και πηγής εμφανίζεται ως «Δεν υποστηρίζεται».

**Ξεκλείδωμα έκτακτης ανάγκης:** δεν χρειάζεται, γιατί η v159 δεν κλειδώνει τίποτα στην τηλεόραση. Για να αφαιρεθεί το όριο έντασης, βγάζετε το «Επιβολή μεγίστου» (εφαρμόζεται στον επόμενο έλεγχο, ~20″). Τοπικά, χωρίς PMS: Ρυθμίσεις → Εφαρμογές → Corali TV → Αναγκαστική διακοπή ή Απεγκατάσταση. Η τηλεόραση επιστρέφει στην κανονική λειτουργία.

- Ροή: πολιτική σε 2 δωμάτια ✓ · εντολή σε εφαρμογή < 1.9 → `APP_TOO_OLD` (δεν στάλθηκε) ✓ · `SET_VOLUME 80` με μέγιστο 50 → αποθηκεύεται cap 50 ✓ · παράδοση μαζί με την πολιτική ✓ · αναφορά 50% → EXECUTED ✓ · χωρίς τιμή → `VALUE_REQUIRED` ✓ · άγνωστα κλειδιά δυνατοτήτων απορρίπτονται ✓ · εφαρμογή 1.8 δεν παίρνει πολιτική ✓.
