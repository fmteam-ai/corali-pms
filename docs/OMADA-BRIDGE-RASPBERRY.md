# Γέφυρα Wi-Fi (Omada) με Raspberry Pi — οδηγίες εγκατάστασης

Το PMS δίνει σε κάθε κράτηση δικό της κωδικό στο Wi-Fi **CORALI_ROOMS** (PPSK στο OC200). Το OC200 είναι προσβάσιμο
μόνο μέσα στο ξενοδοχείο, γι' αυτό ένα Raspberry Pi στο δίκτυο του ξενοδοχείου ρωτά το PMS κάθε λεπτό και
προσθέτει / σβήνει τους κωδικούς στο Omada. Δεν χρειάζεται οθόνη, πληκτρολόγιο ή αλλαγή στο router.

## Τι χρειάζεστε
- Raspberry Pi 4 (1 ή 2 GB), επίσημο τροφοδοτικό USB-C 3A, κάρτα microSD 32GB, κουτί, καλώδιο δικτύου.
- Έναν υπολογιστή με υποδοχή κάρτας (ή αναγνώστη καρτών USB).

## 1. Στοιχεία Omada στο PMS (μία φορά)
PMS → **Ενσωματώσεις → TP-Link Omada · Wi-Fi με κωδικό ανά κράτηση**:

| Πεδίο | Τιμή |
|---|---|
| Interface Access Address | `https://192.168.10.2:443` |
| Omada ID | από Omada → Global → Settings → Platform Integration → Open API → 👁 |
| Όνομα site | `CORALI` |
| Όνομα PPSK profile | `Corali Guests` |
| Όνομα Wi-Fi (SSID) | `CORALI_ROOMS` |
| Client ID / Client Secret | από την εφαρμογή «Corali PMS» στο Open API |

Τσεκάρετε **Ενεργό** → **Αποθήκευση**. Ο «Έλεγχος» θα γράψει ότι η διεύθυνση είναι τοπική — σωστό: τον έλεγχο τον
κάνει η γέφυρα.

## 2. Αρχείο εγκατάστασης
Στην ίδια σελίδα, στην ενότητα **«📶 Γέφυρα Raspberry Pi»** πατήστε **«Λήψη αρχείου εγκατάστασης (user-data)»**.
Κατεβαίνει ένα αρχείο με όνομα `user-data` (χωρίς κατάληξη). **Περιέχει το κλειδί της γέφυρας: μην το στείλετε
σε κανέναν.**

## 3. Γράψιμο της κάρτας (στον υπολογιστή)
1. Εγκαταστήστε το **Raspberry Pi Imager** από το raspberrypi.com/software.
2. Βάλτε την κάρτα microSD στον υπολογιστή και ανοίξτε το Imager.
3. **Device:** Raspberry Pi 4 · **OS:** Raspberry Pi OS (other) → **Raspberry Pi OS Lite (64-bit)** · **Storage:** η κάρτα.
4. Όταν ρωτήσει για **ρυθμίσεις (customisation)**: **No / Όχι** — τα κάνει όλα το αρχείο του PMS.
5. Γράψτε την κάρτα (λίγα λεπτά).
6. Βγάλτε και ξαναβάλτε την κάρτα: εμφανίζεται δίσκος **«bootfs»**. Αντιγράψτε εκεί το αρχείο **`user-data`** του
   PMS και επιλέξτε **Αντικατάσταση** του υπάρχοντος. Βγάλτε την κάρτα με ασφαλή αφαίρεση.

## 4. Σύνδεση στο ξενοδοχείο
1. Βάλτε την κάρτα στο Raspberry (κάτω πλευρά).
2. **Καλώδιο δικτύου** από το Raspberry σε μια ελεύθερη θύρα του switch (TL-SG108E) ή του router.
3. **Τροφοδοτικό** στο ρεύμα. Την πρώτη φορά χρειάζεται 3–5 λεπτά.

## 5. Έλεγχος
PMS → Ενσωματώσεις → TP-Link Omada → **«📶 Γέφυρα Raspberry Pi»**:
- **● Η γέφυρα είναι συνδεδεμένη** και **Omada: OK** → όλα σωστά.
- **Omada: OMADA_AUTH** → λάθος Client ID / Secret / Omada ID.
- **Omada: OMADA_SITE_NOT_FOUND / OMADA_PROFILE_NOT_FOUND** → ελέγξτε τα ονόματα `CORALI` / `Corali Guests`.
- **Omada: OMADA_UNREACHABLE** → το Raspberry δεν βλέπει το OC200 (καλώδιο / δίκτυο).
- **Δεν έχει επικοινωνήσει** μετά από 10 λεπτά → ελέγξτε καλώδιο και ρεύμα (πράσινο λαμπάκι που αναβοσβήνει).

Δοκιμή: check-in μιας δοκιμαστικής κράτησης → σε 1–6 λεπτά η τηλεόραση και το «Η κράτησή μου» δείχνουν το
**CORALI_ROOMS** με τον κωδικό της κράτησης· ένα κινητό συνδέεται με αυτόν. Check-out → σε λίγα λεπτά ο κωδικός
δεν δουλεύει πια.

## Καλό να ξέρετε
- Το Raspberry δεν κρατά δεδομένα πελατών· αν χαλάσει, γράφετε νέα κάρτα με νέο αρχείο από το PMS.
- **Νέο αρχείο εγκατάστασης** = νέο κλειδί: το παλιό Raspberry σταματά να δουλεύει μέχρι να πάρει το νέο αρχείο.
- Αφήστε το πάντα στο ρεύμα. Αν κοπεί το ρεύμα, ξεκινά μόνο του.
